# 万象优选 · 退货验收与售后协同

FDE 训练中心「业务挖掘实验室」练习项目（集团专题项目 `ecommerce-returns`，难度：挑战）。

**场景**：退货签收后，退款还没发生——客户催问、异常件无人认领、三套「完成」口径互不一致。

## 核心结论

- **瓶颈**：「仓库签收 → 排上质检」这段没有任何系统状态，是催问占比 42% 的结构性来源（f10）。
- **代价**：日均 1500 件 × 42% ≈ 630 次催问 × 4 分钟 ≈ 42 小时/日客服工时消耗在「解释等待」上。
- **口径冲突**：客服按到仓、仓库按验收、财务按到账，三套完成口径差 1 098 件（10.5%）。
- **红线**：数据只读、不自动退款、不自动认定欺诈、不绕过账号权限取数（f32、f41）。
